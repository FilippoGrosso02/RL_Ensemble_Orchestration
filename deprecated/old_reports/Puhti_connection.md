## Connecting to Puhti (CSC)

Steps:

- load directory into puhti via ssh 

- install a puhti module: module load python-data

- install all the required dependencies via config file (\config\requirements.txt): pip install -r requirements.txt

- run main.py: e.g. $ python3 main.py --path_name = "ppo1"

- We need some tracking of the progress
